Decided 2026-09-29: HueckoApp moves from native Kotlin/Compose to a single monorepo: `legacy-android/` (old Kotlin app), `mobile/` (Expo + TypeScript, React Navigation: native-stack, drawer, material-top-tabs), `backend/` (Express + TypeScript + Prisma/SQLite, JWT+bcrypt, Zod), AI (Gemini OCR, vote help) lives in `backend/src/ai/` so the API key never ships in the app.

**Why:** Course requires React Native covering Hooks, security and location on Android, and REST API consumption. json-server was rejected because it cannot do auth, business rules or AI calls.
